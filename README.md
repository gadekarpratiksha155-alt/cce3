Mini Project: Shortest Path Finder – Road Network using Graph

Introduction

This project finds the shortest path between locations using graph data structures in C++.

Objectives

- To represent a road network using a weighted, undirected graph.
- To implement Breadth First Search (BFS) and Depth First Search (DFS).
- To find the shortest distance between two locations using Dijkstra's algorithm.
- To perform location search and road network display.

Data Structures Used

- Graph
- Adjacency Matrix
- Arrays

Algorithms Used

- Linear Search
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Dijkstra's Shortest Path Algorithm

Programming Language

C++

File Included

"ShortestPathFinder.cpp"

Applications

- Road network navigation
- Finding shortest routes between cities
- Basic route planning systems

Conclusion

This project demonstrates how graph data structures and algorithms can be used to represent road networks and find the shortest distance between locations.
